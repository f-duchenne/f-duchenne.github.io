Context

We are using site-occupancy models to analyse large databases of occurences such as GBIF. We wanted to use the very nice implementation of spatial autocorrelation in INLA (Rue/lingrdren ?)

We use the available vignettes, but we identified a systematic bias when modelling spatial autocorrelation : the estimated spatial field often has a non-null average (uncentered spatial field), which bias the estimate of the intercept. Although the sum of both remain well estimated, this might be a problem in some context. So we would like to advertise that potential problem.

We start by using the simplest occupancy model possible, where \(z_{i,t}\) represents the presence of a species at year \(t\) and site \(i\).

\(z\) depends on the probability of occupancy \(\psi_{i,t}\) through a Bernouilli law: \(z_{i,t} = \mathcal{B}(\psi_{i,t})\). \(\psi\) can depend on other variables through a logit link, Here we investigate several combinations of the following elements: a fixed intercept, a temporal trend in occupancy and a spatial autocorrelation:

\[\text{logit}(\psi_{i,t}) = \alpha_{0} + \alpha_{t} \times year + \omega_i \]

The second part of the model is the detection part that is simply constituted of a global intercept:

\[y_{i,t,k} = \mathcal{B}(p_{i,t,k} \times z_{i,t}); p_{i,t,k} = \beta_0\]

Each year, a given proportion of sites are visited and detection/non-detection data are generated for every visits of these sites. Here we fix it to 50% the proportion of visited sites for every year. When a site is visited in a given year we replicated visits 20 times per year.

Data simulation

We simulate datasets with the parameters fixed above. First, the occupancy is computed on natural scale, then it is tranformed to the probability scale, and binary outcomes are drawn from this probability. The detections are simulated in the same way.

# Simulating datasets
simulate_datasets <- function(n_sites, n_years, n_visit, prop_visit, max_edge, locs, range, sigma_m, prob_psi, prob_p, n_dataset,trend){
  # Empty list of dataset 
  list_dataset <- list()
  
  for (dt in 1:n_dataset){
  
    sites_list <- 1:n_sites # Spatial 
    years_list <- 1:n_years # Temporal primary 
    visit_list <- 1:n_visit # Temporal secondary 
    n_visited <- n_sites*prop_visit
    
    # Create the visits and sampling effort
    total_sampling <- tibble()
    
    for (i in 1:n_years){
      sampled_year <- sample(sites_list, size=n_visited, replace=FALSE)
      effort <- 1 
      effort_formatted <- tibble(site_id = rep(sampled_year, each = n_visit),
                                 year = rep(years_list[i], n_visited*n_visit),
                                 visit = rep(visit_list, n_visited),
                                 n_sp = effort)
    
      total_sampling <- bind_rows(total_sampling, effort_formatted)
    }
    
    
    # Create the full combinations (empty frame)
    sampling_frame <- setDT(expand.grid(
    site_id = sites_list,
    year    = years_list,
    visit   = visit_list))
    
    sampling_f <-  merge(sampling_frame,total_sampling, by = c("site_id", "year", "visit"),all=TRUE) 
    
    sampling_f <- sampling_f %>%
      arrange(visit, year, site_id)
    
    # Put in right format [sites, years, visits]
    effort_effect <- array(
      sampling_f$n_sp,
      dim = c(length(sites_list), length(years_list), length(visit_list)),
      dimnames = list(
        site  = sites_list,
        year  = years_list,
        visit = visit_list
      )
    )
    
        
    # Create the mesh 
    mesh <- fm_mesh_2d_inla(loc.domain=locs,
                         max.edge = c(1,2)*max_edge,
                        offset=c(max_edge, max_edge*5),
                        cutoff = max_edge/5)
    
    spde <- inla.spde2.pcmatern(
      mesh        = mesh,
      prior.range = c(range, 0.5),   # Put prior centred on real value
      prior.sigma = c(sigma_m, 0.5)
    )
    
    A_sp <- inla.spde.make.A(mesh = mesh, 
                             loc=locs)
    
    
    # Precision matrix
    Q = inla.spde2.precision(spde, theta = c(log(range),
                                                  log(sigma_m)))
    # Simulate the spatial field
    
    sim_field = inla.qsample(n = 1, Q = Q,seed=seed)
    
    omega <- (A_sp %*% sim_field)[,1]
    
    omega_yearly <- cbind(data.table(omega), replicate(n_years -1,omega))
    
    # EMmpty matrix for z
    z <- matrix(nrow = 10000, ncol = n_years)
    
    # Occupancy probabilities
    psi <- as.data.frame(prob_psi+omega_yearly)
    
    z_vec=NULL
    # True occupancy state
    for (i in 1:n_years){
      psi[,i] = psi[,i] + (i-1)*trend
      z[,i] <- rbinom(n_sites, size = 1, prob = inla.link.logit(psi[,i],inverse = T))
      z_vec=c(z_vec,z[,i])
    }

    # Detection probabilities and observed occurrences
    # Create empty matrix to store the results
    y <- array(NA,dim = c(n_sites, n_years, n_visit)) 
      
    # loop over visits
    for (i in 1:n_years){
      for(j in 1:n_visit){
         sites_visited <- which(!is.na(effort_effect[,i,j]))
         prob <- plogis(prob_p)*z[sites_visited, i]
         y[sites_visited,i,j] <- rbinom(n = n_visited,size = 1,prob = prob)
      }
    }

    ##########################
    
    # Get into INLA format
    # Need scale years 
    years_effect <-  array(rep(as.numeric(years_list), each = length(sites_list)), dim = c(length(sites_list), length(years_list)))
    
    year <- as.vector(years_effect)
    # Prepar vector for INLA format 
    INLA_y <- c()
    
    # Visits table 
    for(i in 1:n_years){
      INLA_y = rbind(INLA_y, y[,i,])
    }
    
    # Get which replicates are NA 
    INLA_y_effort <- INLA_y
    INLA_y_effort[!is.na(INLA_y_effort)] <- 1
    
    # Occupancy covariates 
    INLA_occ <- data.frame(
              year_id = year-min(year),
              ID_grid = as.vector(rep(sites_list, n_years)),
              Int_z = 1,
              year_scaled = scale(year),
              x_grid = rep(locs[,1], n_years),
              y_grid = rep(locs[,2], n_years),
              spatialfield=NA,
              true_int = rep(prob_psi, n_years*n_sites),
              occupancy=unlist(c(inla.link.logit(psi,inverse=TRUE))),
              presence=z_vec,
              prob_psi=prob_psi,dataset=dt,
              omega=unlist(c(omega_yearly)),
              trend=trend)
      
    # Detection covariates 
    INLA_det <- data.frame(INLA_y_effort[,1]
                                )
    names(INLA_det) <- paste0(c("DetInt"),"_",1)
            
    for(k in 2:n_visit){
      tmp <- data.frame(INLA_y_effort[,k])
      names(tmp) <- paste0(c("DetInt"),"_",k)
      
      INLA_det <- cbind(INLA_det, tmp)
    }
    
    # Check and remove NAs in observation across visits
    keep = !apply(INLA_y,1,function(x)all(is.na(x)))
    INLA_y = INLA_y[keep,]
    
    # Keep full for predictions
    INLA_occ_pred = INLA_occ
    INLA_occ = INLA_occ[keep,]
    INLA_det = INLA_det[keep,]
    
    # Assemble the data 
    INLA_data = as.list(INLA_occ)
    INLA_data$Y = INLA_y
    INLA_data$X = INLA_det
    
    list_of_data <- list(INLA_data, INLA_occ_pred)
    
    list_dataset[[dt]] <- list_of_data  
  }
  return(list_dataset)
}

Model fit

We also have a function to fit the occupancy model to each dataset and extract outputs.

# Function to analyse the datasets

analyse_dataset_simple <- function(list_of_data, max_edge, range, sigma_m, prob_p){

  INLA_data <- list_of_data[[1]]
  INLA_pred <- list_of_data[[2]]
  true_int <- unique(INLA_data$true_int)
  # Create a mesh for the analysis and spde
  
  mesh <- fm_mesh_2d_inla(loc.domain=locs,
                       max.edge = c(1,2)*max_edge,
                      offset=c(max_edge, max_edge*5),
                      cutoff = max_edge/5)
    
  spde <- inla.spde2.pcmatern(
    mesh        = mesh,
    prior.range = c(range, 0.5), 
    prior.sigma = c(sigma_m, 0.5)
  )
  A_sp_c <- inla.spde.make.A(mesh = mesh, 
                           loc=cbind(INLA_data$x_grid, INLA_data$y_grid))
    
  # Priors
  hyper.prior.list.det <- list(beta1 = list(param = c(0,1/2.72),
                                            initial = 0))
    
  hyper.pc.prec <- list(prec = list(prior = "pc.prec",
                                    param = c(1,0.5)))  
  
  # defining the model formula for each case
  formula <- inla.mdata(Y,X) ~  -1 + Int_z + year_id + f(spatialfield, model=spde,A.local = A_sp_c)
  
  func = function(..., mesh_pred, data_pred){
    res = (Int_z + year_id +
           (mesh_pred %*% spatialfield)[,1])
    return(res)
  }
  
  
  
  model_spat <- inla(formula, data=INLA_data, family= 'occupancy',
                     control.fixed =  list(prec = 1/2.72, prec.intercept = 1/2.72),
                     control.compute = list(waic = TRUE, config = TRUE, residuals = T,return.marginals.predictor=TRUE),
                     control.inla = list(int.strategy = "eb"), 
                     control.family = list(control.link = list(model = "logit"), link.simple = "logit", hyper = hyper.prior.list.det))

  
  ### Extracting spatial field
  field_matrix <- matrix(model_spat$summary.random$spatialfield$mean, 
                         nrow = mesh$n, 
                         ncol = n_years)
  
  field_mean=rep(NA,nrow(INLA_pred))
  vec_years=sort(unique(INLA_pred$year_id))
  for(i in 1:n_years){
    proj.pred <- fmesher::fm_evaluator(mesh, loc = as.matrix(INLA_pred[INLA_pred$year_id==vec_years[i],c("x_grid","y_grid")]))
    field_mean[INLA_pred$year_id==vec_years[i]] <- inla.mesh.project(proj.pred, field = field_matrix[,i])
  }
  INLA_pred$field_mean=field_mean
  
  #extracting model coefficients:
  results_inter <- as.data.frame(model_spat$summary.fixed)
  results_inter$param=c("Intercept","Temporal trend")
  results_inter$true_val=c(unique(INLA_pred$prob_psi),unique(INLA_pred$trend))
  results_inter$prob_psi=unique(INLA_pred$prob_psi)
  results_inter$trend=unique(INLA_pred$trend)
  results_inter$dataset=unique(INLA_pred$dataset)
  results_inter$spatfield_mean=mean(field_mean)
  results_inter$true_spatfield_mean=mean(INLA_pred$omega)
  
  OccEff <- model_spat$summary.fixed 
  DetEff <- model_spat$summary.hyperpar  
  
  A_sp_c_pred <- inla.spde.make.A(mesh = mesh, 
                           loc=cbind(INLA_pred$x_grid, INLA_pred$y_grid))
  
  PostDistSamples <- inla.posterior.sample(250, model_spat) # get coef samples
  
  # Apply function (merge coeff samples w/ new covariates)
  PostDist_newCov <- inla.posterior.sample.eval(func, PostDistSamples,
                                                data_pred = INLA_pred,
                                                mesh_pred = A_sp_c_pred,
                                                HyperParam.summary = DetEff,
                                                Bern.trial = F, parallel.configs = FALSE)
  
  # Get back on probability scale
  PostDist_newCov_inv <- inla.link.logit(PostDist_newCov, inverse = T)
  
  vec1=apply(PostDist_newCov,2,mean)
  vec2=apply(PostDist_newCov_inv,2,mean)
  
  b = data.frame(prob_psi=unique(INLA_pred$prob_psi),
                 dataset=unique(INLA_pred$dataset),
                 trend=unique(INLA_pred$trend),
                 occupancy=mean(INLA_pred$occupancy),
                 occupancy_est1=boot::inv.logit(mean(vec1)),
                 lwr1=boot::inv.logit(quantile(vec1,prob=0.025)),
                 upr1=boot::inv.logit(quantile(vec1,prob=0.975)),
                 occupancy_est2=mean(vec2),lwr2=quantile(vec2,prob=0.025),
                 upr2=quantile(vec2,prob=0.975))
  
  return(list(b,results_inter))

}

Results

We observe than when intercept is a bit high the mean of the spatial field start to be badly estimated, slightly biasing the intercept of the model. However, temporal trend seems to remain unbiased.

Looking at the estimation error of the intercept allows to better visualize the problem:

ggplot(data=subset(results_param,param=="Intercept"))+
  geom_pointrange(aes(x=prob_psi,y=mean-true_val,ymin=lwr-true_val,ymax=upr-true_val),color="green")+
  geom_hline(yintercept=0, linetype="dashed",color="black")+ylab("Error on intercept estimation")+xlab("Simulated Intercept (logit scale)")

Although 0 remains within the 95% confidence interval, there is a clear tendency to over or under-estimate the intercept when it is low and high, respectively. However, once considering intercept and spatial field together this disappears, suggesting that intercept should not be interpreted alone but always in combination with the spatial field.
